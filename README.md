Python Data Science Practicals

About

This repository contains my Python practical programs based on NumPy, Pandas, Matplotlib, Statistics, and Machine Learning. These programs helped me practise data handling, calculations, visualization, and basic prediction techniques using Python.

Practicals:

1. NumPy Array Operations – Perform indexing, slicing, reshaping, and arithmetic operations on arrays.
2. Matrix and Statistical Operations – Perform matrix calculations and statistical operations using NumPy.
3. Pandas Data Inspection – Create or import datasets and display their details and statistics.
4. Data Preprocessing – Handle missing values, remove duplicates, and modify datasets.
5. Filtering and Sorting – Filter and sort data based on given conditions.
6. Grouping and Aggregation – Group data and calculate sums, averages, minimums, and maximums.
7. Data Visualization – Create line plots, bar charts, and histograms using Matplotlib.
8. Scatter Plot and Heatmap – Visualize relationships between variables.
9. Statistical Analysis – Calculate mean, median, variance, standard deviation, and correlation.
10. Linear Regression – Predict numerical values using a linear regression model.
11. Classification – Predict categories using a basic classification algorithm.
12. Mini Project – Student Performance Analysis and Prediction.
    
Libraries Used:

- NumPy
- Pandas
- Matplotlib
- Seaborn
- SciPy
- Scikit-learn

Installation

Install the required libraries using:

pip install numpy pandas matplotlib seaborn scipy scikit-learn

Conclusion

These practicals gave me hands-on experience with Python and helped me understand the basics of data analysis, visualization, statistics, and machine learning.
